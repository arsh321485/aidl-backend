# --- Invite-a-user feature (adds User.ReadBasic.All + Mail.Send + offline_access above) ---
# offline_access lets the backend store a refresh token per admin so it can
# add an invited teammate to the Team via Graph without needing their browser
# open. Mail.Send lets the backend send the invite email from that SAME admin's
# own Microsoft 365 mailbox via Graph (/me/sendMail) — no separate SMTP/Gmail
# account needed; the invite lands straight in the recipient's Outlook/Teams
# mailbox. IMPORTANT: existing admins must log out and log back in via Teams
# ONCE after these scopes are added, to re-consent and get a token stored.
# Azure App Registration → API permissions (delegated) must include Mail.Send
# with admin consent granted.
