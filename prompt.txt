FRONTEND INTEGRATION PROMPT — Land on AIDL dashboard Home tab (NOT Chat/Posts)
==============================================================================
Give this whole file to the frontend engineer.

GOAL
----
After Microsoft Teams login, open Microsoft Teams so the user lands on:

  Team: AIDL
  Channel: aidl dashboard
  Tab: Home   ← welcome card UI (NOT Posts / Chat)

Backend already creates the channel + Home / Learner's Permit / Highway Code /
Traffic Light Check tabs. Frontend must open the correct URL field.

BASE URL
--------
Production backend: https://aidl-backend.onrender.com

============================================================================
CRITICAL RULE (most common bug)
============================================================================
NEVER open `teams_platform_url` as the primary post-login action.

| Field                 | What it opens                         | Use for primary open? |
|-----------------------|---------------------------------------|------------------------|
| teams_url             | AIDL aidl dashboard → Home tab        | YES — always           |
| teams_home_tab_url    | Same as teams_url when Home ready     | YES (alias)            |
| teams_channel_url     | Same Home/channel landing URL         | optional               |
| teams_platform_url    | Generic Teams Chat/home               | NO (only if user clicks "Open chat") |

If you open `teams_platform_url`, user lands on Chat — that is the bug.

============================================================================
STEP 1 — Sign in
============================================================================
GET /api/auth/teams/login/?enroll_as=individual|organization

Frontend:
  window.location.href = data.auth_url

============================================================================
STEP 2 — /auth/callback handler (MUST open teams_url)
============================================================================
Backend 302-redirects browser to:

  https://<frontend>/auth/callback?<params>

Success query params:
  access_token
  refresh_token
  enroll_as
  mode
  email
  full_name
  open_teams=1
  teams_connected=true
  teams_url              ← OPEN THIS (Home tab deep link when ready)
  teams_home_tab_url     ← same as teams_url when Home tab available
  teams_channel_url      ← present when channel/Home ready
  teams_platform_url     ← Chat/home ONLY — do not open by default
  teams_channel_name     ← e.g. "aidl dashboard"
  landed_on              ← "home_tab" | "channel" | "chat"
  teams_setup            ← "ok" | "failed"
  channel_tabs_ok=1      ← tabs installed (optional)
  channel_tabs_created   ← count (optional)
  welcome_card_sent=1    ← optional
  ms_access_token        ← optional Graph token

Required callback logic (Vue / React — same idea):

  const params = new URLSearchParams(window.location.search)
  if (params.get("error")) { showError(...); return }

  // 1) Save tokens FIRST
  saveTokens(params.get("access_token"), params.get("refresh_token"))
  saveUser({
    email: params.get("email"),
    fullName: params.get("full_name"),
    enrollAs: params.get("enroll_as"),
  })

  // 2) Open Teams Home tab — NEVER teams_platform_url here
  if (params.get("open_teams") === "1") {
    const teamsUrl =
      params.get("teams_home_tab_url") ||
      params.get("teams_url") ||
      params.get("teams_channel_url")

    if (teamsUrl) {
      // MUST be synchronous (no await before this) or browser blocks popup
      window.open(teamsUrl, "_blank", "noopener,noreferrer")
    }

    const landed = params.get("landed_on")
    if (landed === "home_tab") {
      toast("Opened AIDL dashboard (Home) in Teams")
    } else if (landed === "channel") {
      toast("Opened AIDL channel in Teams")
    } else {
      toast("Opened Teams (AIDL Home tab not ready yet)")
    }
  }

  // 3) Continue into app
  router.replace("/home")  // or your dashboard route

============================================================================
WRONG vs RIGHT
============================================================================
WRONG (lands on Chat):
  window.open(params.get("teams_platform_url"))

WRONG (ignores Home tab URL):
  window.open("https://teams.microsoft.com/v2/")

RIGHT:
  window.open(params.get("teams_url"))
  // or teams_home_tab_url

============================================================================
STEP 3 — Later "Open in Teams" button
============================================================================
GET /api/auth/teams/launch/
Authorization: Bearer <access_token>

Response:
{
  "teams_url": "<Home tab or channel deep link>",
  "teams_platform_url": "<chat — do not use as primary>",
  "teams_channel_url": "...",
  "landed_on": "home_tab" | "channel" | "chat",
  "channel": { "team_id": "...", "channel_id": "...", "channel_name": "aidl dashboard" }
}

Button click:
  window.open(data.teams_url, "_blank", "noopener,noreferrer")
